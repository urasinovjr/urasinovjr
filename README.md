## Привет, я Даня

Я QA-инженер, тестирую мобильные и веб-приложения. Большую часть проверок делаю руками, а UI-автотесты пишу на Playwright, на TypeScript и на Python.

Сейчас работаю в геймдеве. Команда делает мобильную 4X-игру на Unity для iOS и Android, новая версия выходит раз в две недели, и перед релизом мы в QA-команде её проверяем. До этого я был единственным тестировщиком в небольшой команде и вёл пять клиентских проектов. Среди них были спортивная платформа, страховое приложение, сервис бронирования отелей с арабской локализацией и система видеонаблюдения, для которой я написал e2e-тесты на Playwright.

В IT я пришёл через бэкенд на Python и FastAPI. Поэтому, разбирая баг, я обычно открываю запросы к API и логи, а если нужно, проверяю данные в базе через SQL.
